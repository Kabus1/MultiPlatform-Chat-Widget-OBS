OBS keeps your capture card as a normal Video Capture Device (direct, no Game Capture). TikTok Studio uses OBS Virtual Camera. The card is opened only once, so nothing is locked, in any start order.

  1. OBS: keep (or add) your capture card as Sources › + › Video Capture Device. Remove any Game Capture of this app's window.
  2. Press Set up feed scene. It adds the scene USC TikTok Feed, which shows that same source.
  3. OBS, once: Controls › ⚙ next to Start Virtual Camera › Output Type: Scene › USC TikTok Feed (OBS 30+). With Program, TikTok gets your whole OBS output instead.
  4. Start the Virtual Camera, then in TikTok Studio add a camera source and pick OBS Virtual Camera.

Needs OBS's WebSocket server (Tools › WebSocket Server Settings). The connection settings are in the chat Settings › Advanced › OBS.

Advanced: direct relay window (opens the device itself - only for a card OBS does not use)
